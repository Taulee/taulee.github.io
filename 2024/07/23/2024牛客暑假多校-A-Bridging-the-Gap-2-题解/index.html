2024牛客暑假多校-A-Bridging the Gap 2-题解

原题链接

题意

有一艘船, n 个人想要渡船到河对岸, 船至少要 L 个人开动, 最多可以载 R 个人. 每个人渡过一次船体力 $h_i$ 就会减少 1. 体力不能减为 0.

思路

返回时至少要回去 L 个人, 所以每次返回接人, 就相当于上次最多能运 $R-L$ 个人, 问题就是要运算最多可以返回多少次. 考虑往返一次, 回去接人的人要付出两点体力, 一共需要 L 个人. 返回 x 次, 付出的体力总数是 $2\cdot x\cdot L$ , 但是每个人对其的贡献不能超过 $2x$ , 因为 x 次返回, 同一个人最多往返 x 次. 就可以二分答案找最多的返回次数.

check函数如下: h[i] 预处理成了每个人最多可以返回多少次. 查看总贡献能不能满足 $2xL$ .

for (int i = 0; i < n; ++i) {
    cin >> h[i];
    h[i] = (h[i] - 1) / 2;
}

auto check = [&](int x)->bool{
    int ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += min(x, h[i]);//h[i]之前除过2了
    }
    if (ans >= x * l)return true;
    return false;
};

那么总共最多可以渡河的人就是 $R+x*(R-L)$ , 包含了最后一轮的 R 个度过不用返回的人.

代码:

#define int long long

signed main()
{
    ios::sync_with_stdio(false); cin.tie(nullptr); cout.tie(nullptr);
    int n, l, r;
    cin >> n >> l >> r;
    vector<int>h(n);
    for (int i = 0; i < n; ++i) {
        cin >> h[i];
        h[i] = (h[i] - 1) / 2;
    }

    auto check = [&](int x)->bool{
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            ans += min(x, h[i]);
        }
        if (ans >= x * l)return true;
        return false;
    };
    int times = 0;
    int ll = 0, rr = 1000000;
    while (ll < rr) {
        int mid = (ll + rr + 1) >> 1;
        if (check(mid))ll = mid;
        else rr = mid - 1;
    }
    times = ll;

    if (r + times * (r - l) >= n)cout << "Yes" << endl;
    else cout << "No" << endl;
}
