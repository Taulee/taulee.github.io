Tarjan( 系列3) 有向图中的缩点操作

Tarjan 是大佬的名字, 大佬一生发明了许多算法, 都叫 Tarjan, 我会渐渐整理出来, 想知道都有啥的话, 可以直接到我文章列表搜索 Tarjan.

重温Tarjan, 网上看了许多博客感觉都讲的不清楚. 故传上来自己的笔记, 希望帮到大家.

前置: Tarjan 求有向图中的强连通分量

将有向图中的强连通分量缩成一个点, 权值具题而定.

在 Tarjan 求得 scc 后, 对于每个点打上同样的 scc, 就可以很容易统计出每个 scc 的出度入度有哪些, 就完成了缩点.

vector<int>w(cntscc + 1, 0);
vector<vector<int>>egscc(cntscc + 1);
for (int i = 1; i <= n; ++i) {//缩点
    w[scc[i]]++;
    for (auto c : eg[i]) {
        if (scc[i] == scc[c])continue;//同一个联通量内continue
        egscc[scc[i]].emplace_back(scc[c]);
    }
}
