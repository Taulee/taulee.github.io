Tarjan( 系列2) 在无向图中找割点/桥

Tarjan 是大佬的名字, 大佬一生发明了许多算法, 都叫 Tarjan, 我会渐渐整理出来, 想知道都有啥的话, 可以直接到我文章列表搜索 Tarjan.

重温Tarjan, 网上看了许多博客感觉都讲的不清楚. 故传上来自己的笔记, 希望帮到大家.

如果 无向图 删除某个点/边后，无向图的连通分量数增多，这个点叫割点/边,桥。即把图分为互不相连的两部分。

找割点

用到两个数组:

  1. dfsn[x] : 记录点 x 的 dfs 序.

  2. low[x] : 记录在 dfs 树中, x 向下搜索能到达的最小 dfs 序.

结论:

  1. 对于非根节点: 存在 low[x's son]>=dfsn[x] , 那么 x 就是割点.

  2. 对于根节点: 存在至少两个 low[x's son]>=dfsn[x] , 根节点才为割点.

分析:

以任意点为起点,dfs遍历图, 形成一棵 dfs 树. 更新 low[x] 时, 简单地 low[x]=min{low[x's son]} . 但是注意到, 这样更新到的 low[x's son] 一定大于 dfsn[x] , 因为子树根节点的 dfs 序一定是这棵树里最小的.

怎么做到 low[x's son]<dfsn[x] ? 答案是只能通过返祖边:

  1. dfs过程中不存在横向边, 因为这是无向图, 存在横向边连接到 dfs 之前遍历过的的子树的话, 为什么遍历之前那个子树时, 不就可以把现在这个点纳入子树中了. 否则横向边也是可以使得 low[x's son]<dfsn[x] 的, 因为 dfs 遍历过的子树的 dfs 序一定比现在正在遍历的子树小的. 而 low[x's son] 可以从横向边的另一点更新.

  2. 对于点 x, 当返祖边连接到 x's fa 之上时, low[x] 就可以从这个点更新, 从而小于 dfsn[x's fa] .

所以当 low[x's son]<dfsn[x] 时, 以 x’s son 为根的子树 一定有返祖边连接到 x 的上面. 此时拿掉 x 点,就不会影响图的连通. 若 low[x's son]>=dfsn[x] , 以 x’s son 为根的子树 没有返祖边连接到 x 的上面.(且无横向边) 此时拿掉 x 点. x’s son 为根的子树 就成为一个独立的连通图. 对于根的特殊性, 画画图就知道了.

int dfsn[Maxn], low[Maxn], cnt = 0;
std::vector<int>ans, edge[100010];
void tarjan(int tis, bool rot = true)
{   low[tis] = dfsn[tis] = ++cnt;
    int tot = 0;
    for (auto c : edge[tis])
    {   if (!dfsn[c])
        {   tarjan(c, 0);
            low[tis] = min(low[c], low[tis]);
            tot += (low[c] >= dfsn[tis]);//有一个满足, 它就是割点, 而 tot 就是断开 x 后, 连通分量会增加的个数.(个数这个对吧应该, 我自己分析的)
        } 
        else
        {low[tis] = min(low[tis], dfsn[c]);}
        //使得 low[son]<dfsn[fa] 的唯一办法是存在返祖边通向fa的祖先
        //不能用low[c]更新, 当c=fa时, low[fa],可能以及从fa的其他子树中更新过了, 那么low[c]就会更新到fa的其他子树上.
    }
    if (tot > rot)// 如果是根，tot需要大于1；否则只需大于0
        ans.push_back(tis);
}

找桥

修改 low 的定义：限定返祖边不能是当前点到 fa 的边, 也就是我们来时刚刚经过的边.

所以：

  1. 如果 low[son]<=dfsn[fa] , 说明以 son 为根的子树有一条返祖边连到 fa 或 fa 的上面.

  2. 如果 low[son]>dfsn[fa] , 说明以 son 为根的子树所有边都没连出去. 那 (fa, son) 就是桥.

不修改定义， x的son与x的fa相连的边 (使边 (x, fa) 不是桥)与 x与x的fa相连的边 无法分辨。

void tarjan(int tis, int fa)
{   low[tis] = dfsn[tis] = ++cnt;
    for (auto c : edge[tis])
    {   if (!dfsn[c])
        {   tarjan(c, tis);
            low[tis] = min(low[c], low[tis]);
             if(low[c]>dfsn[tis]){
                 //(tis,c) is bridge
             }
        }
        else if(fa!=c)
        {low[tis] = min(low[tis], dfsn[c]);}//反向边仅在此出现
    }
}
